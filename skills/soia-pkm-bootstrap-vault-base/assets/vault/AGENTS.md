# AGENTS.md · Vault 全局规则

> AI 工作时必读；子目录 `AGENTS.md` 只补充本区规则。

## 分区

- `00_知识库系统/`：vault 元信息与使用说明
- `00_模板/`：可复用模板
- `10_工作台/`：当前状态、下一步、Inbox、交接和执行计划
- `20_资料库/`：去掉当前状态后仍可复用的知识
- `30_日志与思考/`：按日期冻结的日志、调研、决策、审计与复盘证据
- `40_图书视频馆/`：阅读、文章、图书与视频资源
- `50_写作与发布/`：原创草稿和发布留底
- `60_开源项目/`：项目调研与精读
- `90_系统归档/`：不再活跃但需保留的历史

## PKM 执行合同

1. 读根规则与目标区最近的 `AGENTS.md`。
2. 先搜索已有内容和重名，再选分区。
3. 移动、覆盖、批量改名和删除先给 plan；删除必须明确授权。
4. apply 前检查路径越界、目标冲突和源文件漂移；可行时用 SHA-256 manifest。
5. apply 后核对数量、哈希、frontmatter、内部链接和地图；消费端特有视图由对应平台技能验证。
6. 10 区只维护当前状态；冻结证据进 30，稳定知识进 20，历史进 90。

## AI 只读检索

用户只要求查找/回答时不改文件。默认顺序：10 当前 → 20 稳定 → 30 证据 → 40/50/60 专项 → 90 历史。回答给出 vault 相对路径或 wikilink，并标明草稿、待确认、被取代或历史材料。

## 通用约定

- Markdown + YAML frontmatter 是内容真源；聚合交给消费端索引，不在多个文件维护重复列表。
- 文件名全库唯一时用短 wikilink；有重名时用完整路径。
- 不把密码、密钥、token、cookie、私有配置或完整 AI 对话写进 vault。
- `AGENTS.md` 是唯一规则源；其他 AI 入口只做路由。
