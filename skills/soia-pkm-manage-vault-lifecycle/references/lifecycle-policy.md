# Lifecycle policy

Use the customer's root and zone `AGENTS.md` as the authoritative routing policy. Numeric zones are conventions, not universal facts. When no local policy exists, present the 10/20/30/90 model as a proposal and keep all actions in dry-run.

Never infer that an old date means “archived”: open actions, backlinks, supersedes fields, newer control documents and user intent all participate in the decision.
