# SOIA 知识库技能库

知识库本体：bootstrap、整理、提炼、翻译、转换、书库、维护（soia-pkm-*）

## 域说明

本仓负责 `pkm` 域，技能名称统一使用 `soia-pkm-*` 前缀。

## 安装

```bash
npx skills add soia-team/soia-open-pkm-vault-skills -g -a '*' -s <skill> -y
```

本仓属于 SOIA 技能生态，规范真源见 [soia-team/soia-open-skills](https://github.com/soia-team/soia-open-skills)。
